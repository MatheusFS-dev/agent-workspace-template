# Paper Writing Mode

Use this mode for manuscripts, reviewer responses, academic editing, related work, experiment descriptions, limitations, abstracts, conclusions, and rebuttal text.

Always use `.agent/skills/scribe/SKILL.md` for paper-writing tasks.

Do not apply coding-style rules to manuscript prose. Code may be used as technical evidence, but manuscript text must describe mechanisms, methods, assumptions, results, and limitations in academic language.

Do not fabricate citations, venues, results, baselines, reviewer comments, datasets, metrics, or quantitative claims. Do not overstate novelty. Prefer conservative claims that are directly supported by the manuscript or data.

When proposing manuscript edits, explain what problem the new text solves unless the user asks only for final text.
