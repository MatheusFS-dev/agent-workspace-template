# Case: Analysis with a proposed solution

Cover these in order. Each item is a short paragraph unless marked.

1. Open with the recommended solution and its main benefit. Then state the
   problem it fixes, with one piece of evidence.
2. Options (table): two to four options. Columns: option, how it works in a
   few words, benefit, cost or risk.
3. How the recommended solution works, with a diagram of the change or the new
   flow.
4. What the user gives up or risks with this choice.
5. What happens if the user approves, and what decision is needed from them.

Saved report headings: "Options" and "Recommendation".

Keep implementation details out unless the user asks. Name only the files or
parts that change, not how the code is written.
