# Case: Benchmark, simulation, or test results

Cover these in order. Each item is a short paragraph unless marked.

1. Open with what was tested and the main result, including one key number.
   Add the question the run answers and why it matters.
2. Setup and considerations (list): the scenario or data, key parameters with
   values and units, assumptions and simplifications, repetitions or seeds,
   what was not tested or modeled, and where the results stop being valid.
3. How the method or pipeline works, with a diagram when it has three or more
   steps.
4. One small example run traced from input to output with real numbers.
5. Results (table) with the measured numbers, followed by a paragraph on what
   they mean in practice.
6. Surprises, outliers, or failed runs, if any.

Saved report headings: "Considerations" and "Results".

Never report a number the run did not produce. If a run failed or was
skipped, say so in the opening.
