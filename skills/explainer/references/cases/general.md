# Case: General

Use this case when no other case fits. Cover these in order. Each item is a
short paragraph unless marked.

1. Open with the main answer or message, and why it matters to the user.
2. The supporting points, one paragraph each, most important first. Use a
   list only when there are four or more parallel items.
3. One small concrete example, if it makes the points clearer.
4. The action or decision the user needs to take, if any.

Saved report headings: none.

Add a diagram when the content has steps, causes, or parts that connect. Use
a table when comparing items on the same criteria.
