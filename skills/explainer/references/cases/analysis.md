# Case: Analysis

Cover these in order. Each item is a short paragraph unless marked.

1. Open with the main finding. Name what was analyzed, such as data, code, a
   document, or a system, and the question asked about it.
2. Findings (list): three to five items, most important first. Each states
   the finding and its evidence in a few words, such as a number, an example,
   or a location.
3. What the findings mean for the user in practice.
4. What was not checked, and any assumption that could change the findings.

Saved report headings: "Findings" and "Limits".

Add a diagram when the findings involve a structure, a flow, or how parts
relate. Use a table when comparing three or more items on the same criteria.
