# Methods and Experimental Protocol

Load this file for Methods or Experimental Protocol sections.

Explain each nontrivial procedure in reproducible order: input and coordinate frame where relevant, transformation or selection rule, parameters and units, then output. For iterative selection or sampling, state how the first item is chosen and which candidate is selected next; a method name alone is insufficient. Use an equation when prose would leave the operation ambiguous, and define its symbols. Describe performed operations and experimental design; describe storage and indexing when they are the studied method.

For a claimed run total, identify which factors are fully crossed and show their product. Count incomplete or constrained combinations from the realized design, and add baselines only when they are separate. Check the arithmetic and give one worked example when needed. For inference, define the analysis unit, comparison, estimated quantity, test, and practical meaning of the interval or effect. State degrees of freedom and the correction family when applicable. Cite supplied methodological sources where relevant; never invent them.
