# Writing Cover Letters

> **Supporting module:** Part of the Scribe skill. Load it for journal submission and revision cover letters.

## Process

For a LaTeX letter, copy the Scribe asset `assets/cover-letter.tex` as the base. Replace every bracketed placeholder with facts supplied or verified from the manuscript and submission context. Adapt the salutation, title, order, and wording to the target journal's instructions. IEEEtran is the starting class; use the journal's required letter class or format when it differs.

For a first submission, introduce the manuscript and its fit for the journal. Keep `\ManuscriptID` and `\ReSubject` empty so neither label appears, and use initial-submission wording throughout. For a revision, set the heading and opening to the actual revision stage, insert the Manuscript ID only when the journal provides one, and set `\ReSubject` to the context-specific subject without the `Re:` label. Describe only changes actually made and evidence actually available. Mention a point-by-point response letter and blue manuscript changes only if they are actually included. Ask for facts essential to a truthful letter; leave other unknown details as explicit placeholders rather than inventing them.

Keep the salutation, concise submission or revision purpose, supported contribution and fit, closing, and signature. Include declarations such as exclusivity, author approval, conflicts, or ethics only when supplied or required and verified. Apply one reviewer-informed revision pass, then verify the journal, title, editor role, optional ID and `Re:` subject, claims, and mentioned attachments. Do not leave template placeholders in a completed letter.
