# Writing Cover Letters

> **Supporting module:** Part of the Scribe skill. Load it for journal submission and revision cover letters.

## Prepare

Check the target journal's current Instructions for Authors and submission form before drafting. Determine whether it wants a cover letter, a text-box statement, or neither; check the addressee, article type, length, format, and required declarations. For a revision, read the decision letter and establish the revision round. The target journal's requirements take precedence over general publisher advice.

For a LaTeX letter, copy the Scribe asset assets/cover-letter.tex as the base and replace its placeholders with verified facts. IEEEtran is only the starting class; use the journal's required format when it differs. If the journal asks for text in the submission system, use the same content principles without forcing a PDF letter.

## Write the Letter

Address the editor by name when known, and identify the manuscript title, target journal, and article type when relevant. For an initial submission, briefly explain the research question, what was done, the main supported finding or contribution, and why it matters to this journal's readers. Make the fit specific to the journal's stated scope; do not paste the abstract, claim unverified novelty, or invent journal priorities. Keep the letter concise, normally about one page unless the journal asks otherwise.

For a revision, state the actual stage and summarize the few most consequential **completed** changes. Do not duplicate the point-by-point responses. Mention the response letter and blue-highlighted manuscript changes only when those files or markings are actually included. Set \ManuscriptID only if the journal supplied an ID; set \ReSubject only when the context calls for a Re: line. Leave both empty on first submission. If no ID exists at revision, leave \ManuscriptID empty and avoid an ID claim elsewhere.

Close professionally with the appropriate author signature. Include originality, exclusive submission, author approval, conflicts, ethics, related manuscripts, or other declarations only when the journal asks for them or the author supplies them, and only after verifying the facts. If a required declaration cannot be verified, ask before presenting the letter as submission-ready. Ask for other facts essential to a truthful letter; leave nonessential unknown details as visible draft placeholders rather than inventing them.

Apply one reviewer-informed revision pass. Before delivery, verify the editor and journal names, manuscript title, article type, journal fit, revision stage, optional ID and Re: subject, claims, required declarations, and mentioned attachments. Do not leave template placeholders in a completed letter.
